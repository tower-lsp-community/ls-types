*ls-types* was a fork of [*lsp-types*](https://github.com/gluon-lang/lsp-types) to manually merge patches.

This crate was superseded by [gen-lsp-types](https://github.com/ribru17/gen-lsp-types).
It uses the upstream schema to automatically generate the types.
